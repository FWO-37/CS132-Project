# CS132-Project
CS132 Project Submission: Tic-Tac-Toe

Project Description: 

Required Actions To Run Program: 

Just press start. The program runs on its own using user input, so all that is required is a main statement, new = board(), and new.game() in order to start the process. Quite simple really. 

The requirements:
- Winning conditions
- Drawing conditions
- Board represented by lists of lists
- print_board(board) function
- check_winner(board, player) function
- is_draw(board) function
- 2 player
- Alternating turns
- 3 x 3 board
- Must be in terminal
- Take user input
- Prevent invalid moves
